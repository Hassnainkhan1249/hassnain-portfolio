Search algorithms · Agents

Smart Campus Delivery Robot — Classical AI Search

Open source

Six search algorithms implemented from first principles — BFS, DFS, Uniform Cost, A* with configurable Manhattan and Euclidean heuristics, Greedy Best-First and Hill Climbing — plus reflex, goal-based and utility-based agents.

No search library. The dashboard runs all six on the same scenario and reports success rate, path cost, nodes expanded and runtime, which makes the trade-offs concrete: A* expands far fewer nodes than UCS for the same optimal path, Greedy is fast but not cheapest, and Hill Climbing visibly gets stuck on local maxima.

SQL Server · Java · JDBC

HRMS — Human Resource Management System

Open source

A database-backed HR system covering employees, departments, designations, salaries and attendance, with referential integrity enforced by the database rather than by application code.

The interesting part is the schema. Departments references Employees for its manager, while Employees references Departments — a circular foreign key, resolved by creating both tables first and adding the constraint afterwards so the script runs cleanly from scratch. Validation lives in CHECK constraints, so invalid data can't be written even by a different client.

MediChain — Blockchain Medical Records

Repo coming

A decentralised medical record system where access control lives in the smart contract rather than the application layer. Role-based permissions for admin, doctor and patient.

Putting permissions on-chain means a doctor requesting a record they haven't been granted doesn't get a 403 from a server they might bypass — the transaction reverts at the contract level. The patient grants and revokes access, not the hospital.
