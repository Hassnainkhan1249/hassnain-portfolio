# raw csv in, ranked models out
def run(df, target, task="classification"):
    X, y = split_features(df, target)
    X = Preprocessor(
        impute="median",
        encode="onehot",
        scale=True,
    ).fit_transform(X)

    results = []
    for name, model in REGISTRY[task]:
        cv = cross_validate(model, X, y, cv=5)
        results.append({
            "model":  name,
            "score":  cv["test_score"].mean(),
            "std":    cv["test_score"].std(),
            "fit_s":  cv["fit_time"].mean(),
        })

    # accuracy alone lies on imbalanced data
    return rank(results, by="f1_macro")

03 / 06  ·  Blockchain

MediChain

Decentralised medical records where access control is enforced at the smart contract level rather than in the application layer. A doctor requesting a record they were never granted doesn't get a 403 from a server — the transaction reverts. There is no application layer to go around, because the rule doesn't live there. Patients grant and revoke access themselves.

SolidityHardhatEthers.jsNext.jsTailwind

MedicalRecords.sol
mapping(address => mapping(address => bool)) granted;

modifier onlyPermitted(address patient) {
    require(
        msg.sender == patient ||
        granted[patient][msg.sender],
        "NOT_AUTHORISED"
    );
    _;
}

// the patient owns the switch, not the hospital
function grant(address doctor) external {
    granted[msg.sender][doctor] = true;
    emit AccessGranted(msg.sender, doctor);
}

function revoke(address doctor) external {
    granted[msg.sender][doctor] = false;
}
04 / 06  ·  Data Systems

HR Management
System

Database-backed HR platform covering employees, departments, designations, salaries and attendance. The interesting problem was a circular foreign key between Departments and Employees — resolved by deferring the constraint. The schema is idempotent so it re-runs clean, deletes are soft so history survives, and validation lives in CHECK constraints rather than application code.

[x, fs] = audioread('noisy.wav');
frame = round(0.032*fs);  hop = frame/2;

% estimate the floor from leading silence
N = mean(abs(stft(x(1:10*hop), frame, hop)).^2, 2);

X  = stft(x, frame, hop);
P  = max(abs(X).^2 - alpha*N, beta*N);   % subtract
Y  = sqrt(P) .* exp(1i*angle(X));          % keep phase
y  = istft(Y, frame, hop);

fprintf('SNR  %.2f -> %.2f dB\n', snr(x), snr(y));
