Smart Campus Delivery Robot ↗
Classical AI search and intelligent agents

Six search algorithms written from first principles — breadth-first, depth-first, uniform cost, A* with configurable heuristics, greedy best-first and hill climbing — with reflex, goal-based and utility-based agents. No search library. Running all six on one scenario makes the trade-offs concrete: A* expands far fewer nodes than uniform cost for the same optimal path, greedy is quick but not cheapest, and hill climbing visibly gets stuck on local maxima.

HRMS ↗
Employee management, SQL Server and JDBC

Employees, departments, designations, salaries and attendance, with referential integrity enforced by the database rather than application code. The schema is the interesting part: Departments references Employees for its manager while Employees references Departments — a circular foreign key, resolved by creating both tables first and adding the constraint afterwards, so the script runs cleanly from nothing. Validation lives in check constraints, so bad data cannot be written even by a different client.

MediChain
Blockchain medical records

Access control lives in the smart contract rather than the application layer, with role-based permissions for administrator, doctor and patient. Putting permissions on-chain means a doctor requesting a record they were never granted doesn't receive a rejection from a server someone could bypass — the transaction reverts at the contract. The patient grants and revokes access. Not the hospital.
