Smart AutoML Pro

An automated machine learning dashboard that takes a raw tabular dataset through preprocessing, model selection, training, evaluation and prediction — for classification and clustering both — without rewriting the pipeline for each new dataset.

I built it because I was writing the same two hundred lines every time. It compares models side by side and shows where one is failing, rather than reporting a single accuracy figure that quietly hides an imbalanced dataset.

Live Source
02

Smart Campus Delivery Robot

Six classical search algorithms written from first principles — breadth-first, depth-first, uniform cost, A* with configurable heuristics, greedy best-first and hill climbing — alongside reflex, goal-based and utility-based agents.

No search library. Running all six on one scenario makes the trade-offs concrete: A* expands far fewer nodes than uniform cost for the same optimal path, greedy is quick but not cheapest, and hill climbing visibly gets stuck on local maxima.

Python · Streamlit · matplotlib · pandas
Source
03

HRMS

A human resource system covering employees, departments, designations, salaries and attendance, with referential integrity enforced by the database rather than by application code.

The schema is the interesting part. Departments references Employees for its manager while Employees references Departments — a circular foreign key, resolved by creating both tables first and adding the constraint afterwards, so the script runs cleanly from nothing. Validation lives in check constraints, so bad data cannot be written even by a different client.

Java 11 · Maven · SQL Server · JDBC
Source
04

MediChain

A decentralised medical records system where access control lives in the smart contract rather than the application layer, with role-based permissions for administrator, doctor and patient.

Putting permissions on-chain means a doctor requesting a record they were never granted doesn't receive a rejection from a server someone could bypass — the transaction reverts at the contract. The patient grants and revokes access. Not the hospital.

Solidity · Hardhat · Ethers.js · Next.js
